# Unique Mart Website

## Free publishing
Upload all files to a public GitHub repository. Then:
1. Open Settings.
2. Open Pages.
3. Select Deploy from a branch.
4. Choose `main` and `/ (root)`.
5. Save.
GitHub will provide your website link.

## Add product photos
Put your JPG/PNG files inside the `images` folder and name them:
product1.jpg, product2.jpg, etc.
Then update the product list in `script.js` if you add more products.

## Important
The current order button opens an instruction/alert for Instagram ordering. It does not process online payments.
